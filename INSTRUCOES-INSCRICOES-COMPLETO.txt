DEPPI — atualização das inscrições (aluno e DEPPI)

Arquivos front-end alterados:
- src/lib/api.ts
  - registrarRendaFamiliar()
  - enviarDocumentoInscricao()
  - buscarDocumentosInscricao()
  - tipos CategoriaDocumento, DocumentoInscricao e RendaFamiliarInscricao
- src/telas/inscricoes/aluno.tsx
  - grava/atualiza renda familiar
  - calcula renda por pessoa apenas para exibição
  - envia documentos e lista/abre os arquivos
- src/telas/inscricoes/page.tsx
  - inclui a lista e os links dos documentos no detalhe administrativo

Arquivo da API alterado:
- src/services/inscricao.service.ts
  - GET /inscricoes/minhas passa a incluir rendaFamiliar para o aluno visualizar/editar o que já registrou.

Contratos utilizados:
- POST /inscricoes/:id/renda: JSON { rendaFamiliar: number, numeroPessoas: number }
- POST /inscricoes/:id/documentos: multipart/form-data; campos arquivo e categoria
- GET /inscricoes/:id/documentos: resposta { mensagem, documentos }
- A categoria é opcional na API e assume OUTRO quando omitida.
- Upload: PDF/JPG/JPEG/PNG, até 5 MB.
- A abertura do documento usa o campo caminho devolvido pela API (URL pública do Supabase).

Deploy:
1. Atualize e publique a API com a versão ajustada de src/services/inscricao.service.ts.
2. Atualize o front-end com a versão deste ZIP.
3. No front-end execute npm ci e npm run build antes do deploy.

Observação:
- A API atual não incluía rendaFamiliar no GET /inscricoes/minhas; por isso o serviço foi ajustado nesta entrega.
- Os controladores e schemas atuais foram preservados.
